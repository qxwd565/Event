# 이벤트

이벤트(Event) 카드 데이터입니다.


## API 경량화 및 편집 지침 (2026-11-14)

- 공개 카드 API의 필수 파일은 `cards.json`(카드 ID/현재 목록)과 `data/<CARD_ID>.json`(한국 날짜별 최초 상태·변경 내용), `art/`(일반 원화), `golden/`(황금 원화·애니메이션), `frame/`(프레임·텍스처·셰이더)입니다. 실제 없는 자산은 만들지 않습니다.
- `render.json`, `history.json`, `*-date.json` 등의 중복 집계 출력은 배포하지 않습니다. 빌드 과정에서 만들더라도 테스트 전용으로만 취급하며 커밋하면 안 됩니다. 신규 호환/스키마 래퍼를 늘리지 않습니다.
- `data/`가 아직 날짜별 형식이 아닌 경우 **필드와 한국 날짜 근거를 보존하여 날짜 키 형식으로 변환한 뒤** 소비자가 읽게 합니다. 임의 출시일을 지어내거나 현재 능력치를 출시 능력치라고 확정하지 않습니다.
- 최초 날짜는 실제 대전 사용 가능일 기준입니다. 베타는 북미 개시의 한국 시간 환산, 모험모드는 실제 지구 개방일, 이벤트는 실제 개시일입니다. 생성 토큰·선택지도 부모와 최초 실사용을 확인합니다.
- 과거 오기입 날짜 키는 단순 추가가 아니라 잘못된 키를 삭제하고 통합합니다. 변경 기록은 바뀐 필드만 기록하고, 표시용 줄바꿈은 `<br></br>`로 통일합니다. 황금 카드·프레임 바이너리는 재인코딩하지 않습니다.
- `.github/`, `tools/`, 검증 정책 파일은 카탈로그 재생성과 검증에 필요한 것만 유지합니다. 사용 중인 근거·자산을 먼저 삭제하거나 수집 불가 카드/토큰을 누락시키지 않습니다.
